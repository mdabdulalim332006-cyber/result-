Result দেখতে প্রস্তুত?

আপনি সরকারি Education Board Results website-এ যাবেন। সেখানে আপনার ফলাফল দেখার জন্য প্রয়োজনীয় তথ্য নিজেকেই দিতে হবে।

📋

Result দেখার নিয়ম

নিচের ধাপগুলো অনুসরণ করে সরকারি ওয়েবসাইট থেকে আপনার ফলাফল দেখুন

⚠️ তথ্য দেওয়ার আগে মনে রাখুন
  • Roll Number/Institute Code সঠিকভাবে লিখুন।
  • Registration Number চাইলে সঠিক তথ্য দিন।
  • CAPTCHA/Verification থাকলে সঠিকভাবে সম্পন্ন করুন।
  • ভুল তথ্য দিলে ফলাফল নাও আসতে পারে।
  • Result না এলে কিছুক্ষণ পরে আবার চেষ্টা করুন।
  • এই অ্যাপ আপনার কোনো তথ্য সংরক্ষণ করে না।
🌐

আপনি এখন সরকারি Education Board Results website-এ যাচ্ছেন।

💬 আপনি যদি ফলাফল পেয়ে থাকেন, তাহলে আপনার বন্ধুকে ফলাফল পেতে সাহায্য করুন — এখনই শেয়ার করুন 📤

💡 ফলাফল দেখার পর আপনার ফোনের স্ক্রিনশট বা ব্রাউজারের Print/Save as PDF অপশন ব্যবহার করতে পারেন।
